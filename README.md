# TutorLib 🎓

**TutorLib** — это современная онлайн-платформа, разработанная специально для учителей, репетиторов и их учеников. Она автоматизирует рутину, помогает организовывать учебный процесс, планировать занятия и делиться полезными материалами в один клик.

---

## ✨ Основные возможности (Features)

- 📅 **Умное расписание:** Интерактивный календарь для записи учеников с автоматическими напоминаниями о занятиях.
- 📂 **Библиотека материалов (TutorLib):** Удобное хранилище для методичек, домашних заданий и учебников с возможностью делиться ими.
- 📊 **Прогресс учеников:** Наглядная статистика успеваемости, фиксация выполненных домашних заданий и ведение журнала оценок.
- 💬 **Встроенный чат:** Удобная коммуникация с учениками и их родителями без перехода в сторонние мессенджеры.
- 💳 **Учет оплат:** Контроль баланса занятий, фиксация оплат и автоматические уведомления о необходимости пополнения счета.

## 🚀 Быстрый старт (Getting Started)

### Требования (Prerequisites)
Убедитесь, что у вас установлены:
- Node.js (версии 18+)
- Python (версии 3.13+)
- Git

### Установка и запуск фронтенда

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com<ваш-аккаунт>/tutorlib.git
   cd tutorlib/frontend
   ```

2. Установите зависимости:
   ```bash
   npm install
   # или
   yarn install
   ```

3. Запустите сервер для разработки:
   ```bash
   npm run dev
   # или
   yarn dev
   ```
   Фронтенд будет доступен по адресу: `http://localhost:5173` (или `http://localhost:3000`).
